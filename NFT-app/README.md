# The is my first NFT game

This project was created with ReactJS

## The root of module-3 has 2 Solidity files:

"module-3\Authority.sol"
"MyNFT1155.sol"
These files need to be deployed first.
Comments in the files explain in detail how to run this code.

## The frontend is created with React and can be found here:

"\module-3\my-nft-app"

In its project directory, you can run:

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.
