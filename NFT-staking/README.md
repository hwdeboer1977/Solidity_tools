Metana bootcamp: assignment 2

- There is no need to install dependencies separately.
- The assignment consists of 3 parts, and the corresponding Solidity files are in between brackets:

  1. Build an NFT contract and integrate it on OpenSea (MyFirstNFT.sol).
  2. Create an NFT that can be minted with an ERC20 token (MintNFTERC20.sol).
  3. Staking NFTs (stakeNFT.sol).
  4. stakeNFT_v2.sol is an updated version of stakeNFT.sol and requires less actions from the user

- The Solidity file imports ERC20, ERC721, Ownable, IERC721, IERC721Receiver Sol files from Openzeppelin.
- I tested my 3 contracts separately in Remix IDE.
- I added comments to all 3 Solidity files. These comments explain in detail how to run those files.
